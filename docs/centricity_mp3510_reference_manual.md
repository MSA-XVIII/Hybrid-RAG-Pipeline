# Centricity MP3510 Digitizer — Reference Manual

## 1 Introducing the Centricity MP3510
This chapter introduces the Centricity MP3510 Digitizer and its important safety
precautions. The Digitizer scans exposed X-ray cassettes containing an erasable image
plate and forwards digital image data to the image processing station.

## 1.1 Intended use
The Centricity MP3510 must only be used to scan exposed X-ray cassettes containing an
erasable image plate. The device is part of a system consisting of X-ray cassettes with
erasable phosphor image plates, an identification station, and a workstation. It must be
operated only in a radiological environment by qualified staff.

## 1.2 Features
The Centricity MP3510 scans the exposed image plate, converts the information into digital
data, and transfers the image to the image processing station. You can deposit up to 10
cassettes of different sizes in the input buffer. The Digitizer reads demographic data from
the memory chip, removes the image plate, and scans the latent image with a sweeping laser
beam. The Digitizer permits assigning emergency status to an image and re-erasing an image
plate before re-use.

## 1.3 Safety precautions
Make sure the Centricity MP3510 is constantly monitored. Only trained service personnel
must make repairs. Do not override or disconnect the integrated safety features. Check that
the mains voltage is within the specified range. The Centricity MP3510 is a Class 1 Laser
Product using a laser diode of class IIIb. Open the front left and right door only to solve
cassette or image plate jams.

## 1.4 Safety compliance
The Centricity MP3510 complies with the general safety regulations EN 60950, IEC 601-1-1,
UL 2601, CSA C22.2 and the laser safety regulations EN 60825, DHHS/FDA 21 CFR and ANSI Z
136-1980.

## 1.5 Operating modes
The Centricity MP3510 has three operating modes. Operator mode groups basic functions for
radiographers. Key-operator mode groups advanced functions for technicians and is menu
driven. Service mode is reserved for trained service personnel and is password protected.

## 1.6 The user interface
The main components are the cassette input buffer, the cassette output buffer, the keypad
with display, the status indicator, the service connector, and the main switch. The control
panel has a backlit LCD display and ten keys: Emergency, Erase, Key-operator, Service,
Escape, Confirm, Up, Down, Left, and Right. A status indicator light shows green when ready
and red on error.

## 1.7 Switching on the Centricity MP3510
Locate the main switch and place it in position ON. The Digitizer executes a self-test,
initializes the components, and checks the image queue. When the self-test completes, the
operator main screen appears and the status indicator turns constant green.

## 1.8 Resetting the Digitizer
To reset, place the main switch OFF, wait 30 seconds, then place it ON. Never reset the
Digitizer to solve a plate or cassette jam, because the plate inside might get damaged.

## 2 Basic operation (Operator mode)
This chapter explains how to digitize image plates under normal and emergency conditions
and how to erase an image plate to prevent ghost images.

## 2.1 Reading an image plate
Make sure the cassette has been identified via the ID Station. Place one or more cassettes
in the input buffer with the opening mechanism at the bottom. The Digitizer takes in the
first cassette, reads the image plate, and forwards the digital image data to the preview
station and the image processing station. Remove the cassettes from the output buffer.

## 2.2 Reading an emergency image plate
An emergency image plate is given priority by the image processing station. Press the
Emergency key on the keypad, then place the cassette first in the input buffer. The
emergency status is only assigned to the first cassette inserted after pressing Emergency.

## 2.3 Re-erasing an image plate
Re-erase an image plate before re-use if it has not been used for more than 3 days or has
been exposed to an exceptionally high X-ray dose. Press the Erase key, set the number of
plates with the Up and Down keys, and place the cassettes in the input buffer. You can erase
a batch of up to 9 image plates.

## 3 Advanced operation (Key-operator mode)
This chapter covers the advanced key-operator functions accessed via the Key-operator key.

## 3.1 Queue management
As soon as the ID data of an image plate is read, the image identifier is stored in a queue.
Queue management lets you view which images are being transmitted to each image processing
station and their status: in queue, transmitting, warning, exception, or ok. You can delete
images with status in queue, warning, or exception.

## 3.2 Digitizer set-up
Via Digitizer set-up you can enable or disable transmittal of images to all image processing
stations, reroute images to another image processing station, and enable or disable all
audio signals.

## 3.3 Setting the date and time
Select Date and Time in the key-operator menu. Use the Left and Right keys to select a digit
and the Up and Down keys to set its value, then confirm.

## 3.4 Sending test images
To check communication between the Centricity MP3510 and the image processing station, send
a predefined test image. Select the image processing station with the Left and Right keys and
confirm.

## 3.5 System info
System info lets you consult the device data (station name, serial number, AE-title, software
version, total cycles) and the network parameters (hostname, IP address, netmask, default
router, mail host) of the Centricity MP3510.

## 3.6 Installing a new software version
Copy a new software version from floppy disk to the hard disk and activate it. Open the left
front door first, insert the software floppies one by one, then reset to initialize the new
software. Make new backup files afterwards.

## 3.7 Installing a new language
Copy new language files from floppy disk and activate them. Choose from Dutch, English,
French, German, Italian, Japanese, or Spanish for the user terminal language. Make new backup
files afterwards.

## 3.8 Installing new customer parameters
Copy new customer parameter files (CPF-files) from floppy disk and activate them. The image
queue must be empty before you can change the IP address. Make backup files with the new
parameters.

## 3.9 Saving the configuration data (backup)
Via Save configuration you make backup files of the machine specific data onto a diskette.
Open the left front door, insert the backup floppy, and label it with the serial number,
date, and software version.

## 3.10 Enabling or disabling fast preview
If fast preview is enabled, the Digitizer transmits digital image data in blocks of typically
100 lines to the preview station, letting you quickly assess whether the exposure was
successful.

## 4 Preventive maintenance and troubleshooting
This chapter covers preventive maintenance and troubleshooting procedures.

## 4.1 Preventive maintenance
The Centricity MP3510 is designed for trouble-free service. Do not lubricate or disassemble
the Digitizer. Switch off and disconnect the power cord before cleaning. Wipe the exterior
with a soft damp cloth and a mild detergent; never use an ammonia-based cleaner and take
care that no water infiltrates the machine.

## 4.2 General procedure in case of malfunction
The display provides information about errors. The status changes from READY to Warning,
Locked, or Error. Follow the instructions on the display. Never reset the Digitizer to solve
a cassette or image plate jam nor to solve communication problems.

## 4.3 Solving the ERROR status
There are two types of errors. Errors solved by the key-operator show ERROR XXXXX (for
example an image plate jam). Errors that require a trained service engineer show SERVICE
XXXXX; reset the Centricity MP3510 and contact your service organization with the error
number.

## 4.4 Clearing cassette jams
A cassette can jam when the Digitizer takes in or returns a cassette. Switch off the
Centricity MP3510, push the black handle to unlock the front doors, open the left front door
first, then the right, and gently remove the jammed cassette. If it is hard to reach in the
output slot, swivel the cassette unit anti-clockwise.

## 4.5 Clearing image plate jams
The Digitizer reads and digitizes the plate first, then erases it. A plate can jam in the
pre-scan unit, the scanner, or the post-scan unit. Remove the cassette, check where the plate
is jammed, and pull the plate carefully towards you while preventing exposure to daylight.

## 5 Specifications
The Centricity MP3510 Digitizer, model 5146/2xx, measures 840 mm wide and 1420 mm high and
weighs 320 kg unpacked. Maximum power consumption is approximately 1700 W. The cassette buffer
holds 10 cassettes of mixed sizes. Throughput is up to 80 plates per hour at high resolution
and 95 plates per hour at standard resolution, with 12 bits per pixel grayscale resolution.
